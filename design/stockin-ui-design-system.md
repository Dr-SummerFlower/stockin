## 1. Design Context（设计上下文）

> 本节区分「用户已确认」与「设计默认值」，不把设计推断写成用户事实。

### 1.1 用户与场景（来自项目交付方案 v1.1，用户已确认口径）

- **使用者**：个体商家**本人**，单账户、个人自用，非团队协作、无多角色。
- **使用情境**：桌面浏览器为主（`http://IP:PORT`），手机浏览器也须能完成**全部**业务功能（F1 响应式 Must 保留）。
- **要完成的三件事**：① 打开录入页到保存成功 ≤30 秒；② 开屏即得 6 组指标与临期/过期风险，不需二次筛选；③ Excel 导入/导出无损往返。
- **技术约束**：Umi 4 + React 18 + Ant Design 5、纯 HTTP 非安全上下文、CSP `default-src 'self'`、1 核 1G 单容器、**零图表库**、零外部 CDN、无 PWA/SW。

### 1.2 用户本轮明确选择

| 参数 | 选择 |
|------|------|
| 设计对象 | **重做现有进货统计界面**（业务功能 28 条 Must 不变） |
| 交付形态 | **高保真原型 + 设计规范** |
| 视觉调性 | **清爽现代 · 浅色** |

### 1.3 品牌性格（设计默认值，可被推翻）

**克制 / 可信 / 清爽**。这是账本工具，不是营销页：界面应该安静、有秩序、让数字说话，不制造视觉噪音。

### 1.4 美学方向与反参考

- **方向**：浅色纸感画布 + 墨绿主色 + 票据式等宽信息带，带一点编辑排版气质。
- **反参考（明确不要长成这样）**：现有实现的深蓝顶栏 `#001529`、纯文字符号导航（`▦ ☰ ⚙`）、满屏等大白卡；以及通用 AI 后台审美（紫蓝渐变、发光描边、6 个等大英雄指标卡一字排开、万物皆卡片、居中一切）。
- **记忆点**：顶部「票据抬头」——虚线 + 等宽字体呈现基准日 / 阈值 / 数据源，像收据抬头；指标编号 ①②③④ 沿用业务既有口径并风格化。

### 1.5 五条设计原则

1. **开屏即得**：首屏不滚动就能读到 6 组指标与风险清单，风险信息优先于装饰。
2. **30 秒录入**：表单按「基础 → 日期组 → 金额组」三步线性推进，自动值与手填值一眼可辨。
3. **风险不刺眼**：临期/过期用颜色 + 文字 + 左侧色条三通道，不用大面积红块。
4. **密度可读**：金额用 tabular-nums、表格用细分隔线、层级靠留白与字重而非层层套卡。
5. **一致且可达**：4pt 间距、44px 触控、WCAG AA 对比度、可见焦点、`prefers-reduced-motion`。

## 3. 设计基础（Design Foundations）

### 3.1 色彩系统与对比度实测

中性色带极轻绿调（避免纯灰的「死感」），主色为墨绿，语义色为陶土橙 / 砖红 / 松绿。**不使用纯黑 `#000`、纯白 `#fff` 作为大面积表面**。

| 令牌 | 值 | 用途 | 实测对比度 |
|------|-----|------|-----------|
| `--canvas` | `#F7F8F6` | 页面画布 | — |
| `--surface` | `#FDFDFC` | 面板 / 输入 / 导航 | — |
| `--surface-2` | `#F1F4F1` | 表头 / hover / 展开行 | — |
| `--ink-900` | `#1B2421` | 主文本 | **15.62:1** on surface ／ 14.92:1 on canvas |
| `--ink-600` | `#4F5A55` | 次文本 | **7.05:1** |
| `--ink-400` | `#616D67` | 弱文本 / 占位符 | **5.30:1** on surface ／ 5.07:1 on canvas |
| `--line` | `#E1E6E2` | 装饰性分隔线 | 1.24:1（装饰，非必需边界） |
| `--line-strong` | `#8A958E` | **输入框 / 控件边界** | **3.05:1**（满足 UI 组件 3:1） |
| `--brand` | `#1F6B52` | 主色 / CTA / 选中态 | **6.28:1** 文字 ／ 白字 6.40:1 |
| `--brand-hover` | `#18573F` | 主色 hover | — |
| `--brand-100` | `#E8F2ED` | 选中底 / 聚焦光环 | 主色文字 5.59:1 |
| `--warn` | `#9C4F06` | 临期 | **5.32:1** on `--warn-100` ／ 5.84:1 on surface |
| `--warn-100` | `#FBF1E4` | 临期底 | — |
| `--danger` | `#B3261E` | 过期 / 破坏性操作 | **5.61:1** on `--danger-100` ／ 6.42:1 on surface |
| `--danger-100` | `#FBEAE8` | 过期底 | — |
| `--auto` | `#2F6B3A` | 自动推算 | **5.64:1** on `--auto-100` ／ 6.28:1 on surface |
| `--auto-100` | `#EAF3EB` | 自动值底 | — |

> 计算方式：WCAG 2.x 相对亮度 + `(L1+0.05)/(L2+0.05)`，脚本实测于 2026-11-10。设计过程中已把未达标的三处调深：弱文本 `#6E7A74`(4.39:1) → `#616D67`、临期 `#B25E09`(4.18:1) → `#9C4F06`、并新增 `--line-strong` 承担控件边界。
> **60–30–10 权重**：约 60% 中性画布与留白、30% 文本与分隔线、10% 主色强调；主色不铺满。

**暗色令牌**（`[data-theme="dark"]`）：`#121A17` 画布 / `#18221E` 面板 / `#EDF2EF` 主文本 / `#5DBB92` 主色。暗色靠更亮的表面建立层级，不靠阴影；主色去饱和。**深色为设计系统能力预览，非本期实现范围。**

### 3.2 字体系统

**不引入任何外部 Web Font**——纯 HTTP + CSP `'self'` + 零 CDN + 1 核 1G 的前提下，系统字体栈是唯一稳妥选择，也避免首屏字体闪烁。

| 用途 | 字体栈 | 规格 |
|------|--------|------|
| 中文 / UI | `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` | 正文 14px / 1.6，字重 400–650 |
| 数字 / 日期 / 编号 | `"SF Mono", "JetBrains Mono", "Cascadia Mono", ui-monospace, Consolas, monospace` | 12px，`tabular-nums` |
| 金额与大数 | 同 UI 栈 + `font-variant-numeric: tabular-nums` | 字重 380–400，字距 `-.035em`，避免加粗造成跳动 |

| 阶 | 尺寸 | 字重 | 字距 | 用途 |
|----|------|------|------|------|
| Hero | `clamp(26px, 2.8vw, 36px)` | 380 | -0.035em | 指标数值 |
| H1 | `clamp(22px, 2.4vw, 28px)` | 650 | -0.025em | 页面标题 |
| H2 | 16px | 650 | -0.01em | 面板标题 |
| Body | 14px | 400 | 0 | 正文 / 表格 |
| Caption | 13px | 400 | 0 | 辅助说明 |
| Micro | 11–12px | 600 | 0.05em | 表头 / 标签 / 票据抬头 |

### 3.3 间距、圆角、阴影、动效

- **4pt 基准**：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px`（`--s1 … --s16`）。命名用语义而非数值。同级间距用 `gap`，不用 margin，避免外边距塌陷。
- **节奏**：区块之间 24–32px，区块内 12–16px，标签与控件之间 4–6px。刻意不处处相等，用间距变化建立层级。
- **圆角**：`6px` 控件 / `10px` 面板 / `14px` 模态框；不套娃。
- **阴影**：仅 3 级，`sm` 几乎不可见；浮层才用 `lg`。面板默认靠 1px 边界而非阴影分层。
- **动效**：`150ms` 状态变化（背景 / 边框 / 颜色），`260ms` 视图淡入；缓动 `cubic-bezier(.25,1,.5,1)`（ease-out-quart）。**不做位移弹跳、不做布局属性动画**；`prefers-reduced-motion: reduce` 时全部降至 0.01ms。

## 4. 组件库规格

| 组件 | 尺寸 / 结构 | 状态 | 用法约束 |
|------|------------|------|---------|
| **主按钮** | 高 40px（`--sm` 34px），内边距 0 15px，圆角 6px，主色底 + `--on-brand` 文字 | 默认 / hover（深一档）/ focus-visible（2px outline + 2px offset）/ disabled（opacity .5，禁交互） | 每屏**最多 1 个**主按钮；表单提交、新增记录 |
| **次按钮 / 文字按钮** | 同高；次按钮 1px `--line-strong` 边框；文字按钮无边框 | hover 主色文字 + `--brand-100` 底 | 导入、导出、刷新、取消 |
| **危险按钮** | 同上，`--danger` 底 | — | 仅用于二次确认弹窗内的最终动作 |
| **输入框** | 高 40px（手机 44px），1px `--line-strong`，圆角 6px | 默认 / hover（主色边）/ focus（主色边 + 3px `--brand-100` 光环）/ error（`--danger` 边 + 文案）/ readonly（浅底） | **label 必填**；placeholder 用 `--ink-400`（5.30:1，满足 4.5:1） |
| **状态标签** | 高 20px，圆角 20px，1px 同色边框 + 5px 圆点 + 文字 | `临期 / 已过期 / 正常 / 自动推算 / 手填 / 未填写` | 颜色 **永不单独**承载语义；必须带文字 |
| **指标单元** | 指标带内 1/4 栏，上下 24px / 16px，右侧 1px 分隔线 | — | 大数用 tabular-nums，超长省略不换行 |
| **风险块** | 3px 左侧色条 + 语义浅底 + 30px 数值 | 临期 / 过期 | 与指标带视觉区分，强调风险权重 |
| **预警行** | Grid：左主信息 / 右金额；左侧 3px 状态条；行高 ≥ 56px | hover 浅底 | 顺序由服务端排定，前端不二次排序 |
| **表格** | 表头 11px 大写微标 + 浅底；行 12px 上下内边距；细分隔线；无外框卡片（仅容器 1px） | hover 行底纹 / 选中 / 展开 | 数值列右对齐 + tabular-nums；操作列固定右侧 |
| **侧导航** | 宽 224px；项高 44px；选中态 `--brand-100` 底 + 3px 左竖条 | 默认 / hover / active | 图标 + 文字；平板退化为 76px 图标栏，手机退化为底部 5 项 Tab |
| **面板** | 1px `--line` + 10px 圆角；头部 16/24px 内边距 + 底分隔线 | — | 仅用于真正独立且可操作的区块 |
| **筛选条** | 默认 3 控件一行；「更多筛选」展开其余 | 展开 / 收起 | 与导出共用同一份 `RecordFilter` |
| **表单分组** | 编号徽标 + 标题 + 一句说明 + 分隔线 + 内容区 | 未锁定 / 已锁定（标签明示「不重算」） | 三组线性排列；侧栏放技术口径 |
| **Toast** | 右下滑入，最深 3200ms，主色勾图标 | — | 成功反馈；错误信息不用 Toast 而用行内提示 |
| **确认弹窗** | 宽 420px，14px 圆角，遮罩 + 明确后果文案 | — | 单条删除 / 批量删除 / 彻底删除**必须**二次确认 |
| **空状态** | 图标 + 一句结论 + 下一步动作 | — | 有教育意义，不只写「暂无数据」 |

## 5. 页面设计说明

### 5.1 统计大屏 `/`（核心页）

- **布局**：页头 → 票据抬头信息带 → 4 项指标带 → 左「预警清单」(≈1.9fr) / 右「风险栏」(≈1fr)。
- **信息层级**：风险 > 累计指标 > 元信息。6 组指标按业务编号 ①–⑥ 完整覆盖，**不删、不改口径**；只是把 ⑤⑥ 从平铺卡片移到独立风险栏。
- **票据抬头**：基准日、阈值 X、数据源、同步状态；等宽字体 + 虚线边界，是本套设计的识别点。
- **开屏即得**：一次 `GET /api/dashboard`，无需筛选或刷新；基准日与阈值以服务端为准，前端不重算临期状态。
- **清单**：状态色条 + 文字标签 + 剩余天数 + 到期日 + 金额，颜色/文字/位置三通道。

### 5.2 进货记录 `/records`

- 工具条：模板 / 导入 / 导出 / 新增记录（**仅「新增记录」为主按钮**）。
- 筛选渐进披露：默认 商品名称、到期状态、排序；展开后补齐规格与 4 个日期条件。
- 主表 8 列：商品名称、进货日期、到期日期、规格、单价、数量、金额、状态 + 操作；行展开查看生产日期 / 保质期 / 备注 / 创建时间 / 来源标记。
- 选中行后出现批量操作条（主色浅底 + 1px 主色边界），批量删除走二次确认。
- 分页保留总数与页码；筛选与导出共用同一份条件，导出范围 = 当前筛选 ∩ 日期范围。

### 5.3 新增 / 编辑记录 `/records/new`

- **三步线性**：01 基础信息（4 字段）→ 02 日期组三选二 → 03 金额组三选二，右侧 sticky 侧栏放联动规则与来源图例（技术口径不干扰主流程）。
- **来源三态可视化**：`自动推算` 绿底 + 绿标签，`手填` 中性标签，`未填写` 虚线标签；自动值输入框带浅绿底。
- **锁定反馈**：手动覆盖自动值后，分组头部标签变为「已锁定 · 不重算」，对应值不再被推导覆盖。
- **底部提交条**：桌面普通行内；手机 `position: sticky`（位于底部 Tab 之上），两个按钮等宽 ≥44px。
- 原型中的联动 JS 仅用于**演示**；业务实现仍由 `@stockin/domain` 的 `applyFieldEvent` / `computeDateGroup` / `computeAmountGroup` 单一真源承担，服务端只校验不重算。

### 5.4 回收站 `/trash` · 操作日志 `/logs`

- 回收站：轻量行列表，恢复 / 彻底删除（二次确认）；说明「删除一律软删」。
- 操作日志：时间线而非表格，突出 append-only 的语义；展示动作、对象、时间与 `requestId`；无编辑/删除入口。

### 5.5 设置 `/settings`

- 仅临期阈值 X 一项可改（含等号语义说明）；备份区只展示元数据与「立即备份」，**不出现下载动作**（接口无下载端点）。

### 5.6 登录 `/login` · 初始化引导 `/setup`

- 独立页，左品牌区 + 右表单；明确纯 HTTP 明文传输提示与首次登录强制引导的说明。
- `/setup` 在原型中未单独绘制（形态与登录一致：单栏卡片 + 新账密 + 确认），落地时沿用同一令牌与组件即可。

### 5.7 设计系统 `/design-system`（原型附加视图）

- 色板、字阶、间距刻度、按钮/标签/表单状态、可达性基线一览，供评审与开发对照。

## 6. 关键流程与「符合用户习惯」的依据

| 用户习惯 | 本方案的对应设计 |
|---------|-----------------|
| 打开就想知道「现在有没有风险」 | 首页首屏风险清单 + 风险栏，无需筛选；风险项视觉权重高于累计值 |
